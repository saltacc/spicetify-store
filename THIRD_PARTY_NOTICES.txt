Spicetify code and data

Copyright the Spicetify contributors. The following materials, including the
store's adaptations of them, are provided under the GNU Lesser General Public
License v2.1. The Spicetify Store contributors marked their modifications in
the affected source files and the adjacent .license files for JSON data.

* data/cssMap.json and data/icons.json contain the CSS class dictionary and
  SVG path markup from spicetify/cli. SpotiKit's generator filtered class
  entries and extracted the SVGIcons entries. On 2026-11-17 the store
  repackaged those dictionaries as JSON.
  https://github.com/spicetify/cli/blob/0b4653f6e6f15efd88119aad96386fb309e81477/css-map.json
  https://github.com/spicetify/cli/blob/0b4653f6e6f15efd88119aad96386fb309e81477/src/jsHelper/spicetifyWrapper/icons.js
  Intermediate SpotiKit file Framework/api/14-spicetify-data.js
  Intermediate file SHA-256 24636ab8b4c55d2f38302b1b3bea846385a57c47bcb59b112b32e612554f70d4
* The old bridge carries forward Spicetify's player event and playback helpers
  (src/compat/player.js), keyboard mapping and shortcut helpers
  (src/compat/controls.js), color extraction (src/compat/services.js), and
  popup markup, styles and class-name helper (src/compat/popup.js).
  Corresponding Spicetify wrapper sources include core.js, player-events.js,
  helpers.js and popup.js.
  https://github.com/spicetify/cli/tree/8c92e3067de9659caca4c9da7979da3897458e27/src/jsHelper/spicetifyWrapper
* src/compat/tooltips.js adapts the tooltip renderer and lifecycle callbacks
  from Spicetify v2.45.3. On 2026-11-17 the store adapted them to headless
  Tippy, added lifecycle cleanup and changed how hidden tooltips unmount.
  https://github.com/spicetify/cli/blob/8c92e3067de9659caca4c9da7979da3897458e27/src/jsHelper/spicetifyWrapper/popup.js

The distribution includes each component's original license text and notices.

  licenses/Acorn-AUTHORS.txt.
